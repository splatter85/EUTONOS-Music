For the concept, read Product goal → Architecture → Library and transitions → Test app. For making music, start in the guide index. For implementation, read AGENTS and Current Tasks, then the selected campaign stage and its inputs.

All runtime descriptions are proposals unless an implementation checkpoint explicitly qualifies them. A linked upstream project may provide a capability; that does not mean it is installed, tested or integrated here.
