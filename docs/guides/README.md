# Music and production guidebook

This guidebook teaches the musical decisions and production workflow behind the proposed engine. It is written for a creator learning the vocabulary and for an assistant translating a plain-language brief into editable, reviewable music.

## Start without a music background

Read the foundations through rhythm, chords and motifs. Choose one family in Genre recipes. Make a short phrase in FL Studio, then use the arrangement guide to turn it into several related sections. Audition the result before adding procedural variation.

You do not need to learn every term before giving a useful brief. “Keep the bass but make the percussion less busy” is a valid direction. The agent guide explains how an assistant should translate that into a bounded proposal while preserving what already works.

## Build an adaptive pack

Use FL Studio workflow → Arrangement/mixing → Recipe authoring → [Library and transitions](../LIBRARY_AND_TRANSITIONS.md). Decide which aspects are authored audio, which are editable notes, and which the runtime may vary. Prepare several musical identities within the target moods and review the combinations the engine will actually play.

## Add vocals

Read [Vocals and models](../VOCALS_AND_MODELS.md) before choosing a tool. Then use Vocal production to prepare a brief/score, render alternatives, check pronunciation and expression, and export phrases or finished sections under the applicable terms.

## Scope and use

These guides offer a broad foundation and a method for extending the catalogue, not a claim to exhaust every musical tradition. Genre labels overlap and evolve. Ranges and patterns are starting examples; listen to relevant original music, identify the specific tradition/substyle, and adapt deliberately.

Examples are original proposals unless a source is identified. No audio was produced or auditioned as part of writing this baseline. Keep that distinction when using the guides as agent context.
